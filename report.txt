=== Q1 ===
# Why is the agent's first move east rather than north in Figure 1(a) of
# the handout, given that it does not yet know which cells
# are blocked?  Then: why are Manhattan
# distances consistent when the agent may move only in the four compass
# directions and every move costs one?

The agent moves east instead of north because A* uses the cost so far and the estimated distance to the goal to choose its next move.

Since it assumes unknown cells are free, east appears to have a lower total estimated cost based on what the agent knows.

Manhattan distance is consistent because moving one cell in any of the four directions changes the distance to the goal by exactly 1. Since each move costs 1, h(n) <= 1 + h(n') holds for neighboring cells, and h(goal) = 0.


=== Q2 ===
# Why must the agent either reach the target or discover that it cannot, in
# finite time?  Give the argument, and the reason the number of moves is bounded
# above by the number of unblocked cells squared.
The agent finishes in finite time.

Repeated Forward A* will eventually reach the target or determine it cannot be reached. Each time A* finds a path, the agent follows it until it reaches the goal or finds a blocked cell.

When it finds a blocked cell, it updates the grid and plans again. Since the grid is finite, it cannot keep discovering new blocked cells forever.

If n is the number of unblocked cells, each planned path has at most n moves. The agent can replan at most n times, giving a maximum of n² moves.

=== Q4 ===
# Compare Repeated Backward A* and Repeated Forward A*. Explain how newly
# discovered blockages affect the two directions. Say where each search
# starts and how that start moves between replans.
The similarity between repeated forward and backward A* is that after the character moves, its position then changes, but the goal is still the same. Forward A* searches from the character to the goal using the new map after an obstacle is found. Backward A* searches from the goal to the character, and its solution is reversed. Both Repeated Forward and backward A* also use the new map to find a new path or route when they discover that the path they were first planning to use has an obstacle.

=== Q7 ===
# Prove the w-times-optimal bound for a consistent base h without reopening.
# Interpret the sweep and choose a weight. How can replanning affect the
# trade-off? Can Adaptive A* safely learn C-g(s) from a weighted search?
Weighted A* guarantees a path cost within a factor of w of the optimal cost when using a consistent heuristic. Increasing the weight reduced expansions with a small increase in path cost, making it the best balance between speed and quality. However, obstacles can increase total search effort and travel distance. Adaptive A* should always use a weight of 1 because higher weights can make its learned heuristic inaccurate and break its guarantees.
